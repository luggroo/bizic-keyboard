学堂版仅在安装包内提供文献书目和原件链接。词典、例句、语料和参考语法仍可离线使用。

| 安装包 | 功能 |
| --- | --- |
| `bizic-academy-0.4.1.apk` | 学堂和土家语输入法，支持本机手写识别 |
| `bizic-academy-0.4.1-no-handwriting.apk` | 学堂和土家语输入法 |
| `tujia-keyboard-0.4.1.apk` | 纯输入法，支持本机手写识别 |
| `tujia-keyboard-0.4.1-no-handwriting.apk` | 纯输入法 |

四个包使用相同的应用 ID 和正式签名。请选择一个，可覆盖安装 0.3.6 或同签名的 0.4.0 测试包。

学堂中的翻译指南提供示例及提示词编辑。外部资料和第三方服务链接经用户确认后由系统浏览器打开。键盘操作诊断默认开启，可在输入法设置中关闭。诊断记录保存在设备上，用户可主动复制或通过邮件应用分享。

`SHA256SUMS` 用于核对下载文件。
