## 选择安装包

四个安装包使用与 0.3.6 相同的签名和应用 ID，请选择一个安装：

- **学堂，有手写**：词典、例句语料、翻译工具、语言知识和完整输入法。
- **学堂，无手写**：学堂和键盘输入，不含手写识别模型。
- **纯输入法，有手写**：输入法及设置，不包含学堂资料。
- **纯输入法，无手写**：仅键盘输入及设置，不含学堂资料或手写识别模型。

各版本可以相互覆盖安装；从 0.3.6 升级时请勿先卸载，以保留应用数据。升级前建议备份重要的个人数据。

**应用本身不联网。** 词典和语言资料随安装包提供；翻译工具提供使用说明和示例，调用外部服务时由系统浏览器打开。键盘操作诊断默认开启，记录仅保存在本机，可在设置中关闭。

`SHA256SUMS` 可用于核对下载文件的完整性。
