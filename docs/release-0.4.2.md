# 毕兹辞谱 0.4.2

首轮送审包是 `bizic-cipu-0.4.2-keyboard-typing.apk`。

| 版本 | 功能 |
| --- | --- |
| keyboard-typing | 系统输入法与设置。支持北部土家语带调号拼写、叶氏拼音、汉字记音和国际音标输入。 |
| keyboard-handwriting | 系统输入法与设置，另支持本机手写识别。 |
| academy-typing | 系统输入法、词典、参考语法、例句语料和书目。原件链接经确认后交由浏览器打开。 |
| academy-handwriting | 词典、语言资料和系统输入法，另支持本机手写识别。 |

**纯输入法无手写版商店简介**

毕兹辞谱是一款北部土家语离线输入法，支持带调号拼写、叶氏拼音、汉字记音和国际音标输入。输入、候选和个人词库均在本机处理。

**审核操作说明**

打开应用后查看隐私说明，再从设置进入系统键盘管理，启用并切换到「毕兹辞谱」。可在应用内试打区验证。断开网络后仍可使用上述功能。基础崩溃日志仅存设备，附带键盘操作默认关闭。用户如主动开启，可随时关闭；可以在设置中查看或删除现有日志，也可以主动复制或交由邮件应用分享。

**隐私政策网页草稿**

本应用不申请联网权限，输入、候选和个人词库在本机处理。个人词库学习默认开启，可在键盘设置中关闭或清空。键盘崩溃时，应用在设备上覆写一份基础日志，包括崩溃时间、应用与 Android 版本、线程名、错误类型及调用栈。附带键盘操作默认关闭。开启后，崩溃报告可能包含普通文本框最近 64 次键盘操作，包括按键与选词。特殊字段根据宿主应用提供的 Android 输入框标记跳过。密码、数字等填在普通文本框时仍可能被记录。可在设置中关闭附带记录或删除日志。主动复制报告会使用系统剪贴板，选择邮件反馈会把报告交给邮件应用。应用本身不上传日志或词库。

运营者和联系方式请在上线前按两家开发者账号实际主体填写，并将正文部署为可公开访问的 HTTPS 页面。
