毕兹辞谱是土家语离线词典与输入法。0.4.2 统一了应用名称，更新了学堂版的阳雀图标，并将「附带键盘操作」设为默认关闭。

## 选择安装包

| 安装包 | 适合 |
| --- | --- |
| `bizic-cipu-0.4.2-keyboard-typing.apk` | 只用输入法。支持带调号拼写、叶氏拼音、汉字记音和国际音标。 |
| `bizic-cipu-0.4.2-keyboard-handwriting.apk` | 只用输入法，另含本机手写识别。 |
| `bizic-cipu-0.4.2-academy-typing.apk` | 需要词典、参考语法、语料、书目和输入法。 |
| `bizic-cipu-0.4.2-academy-handwriting.apk` | 需要词典、语言资料和输入法，另含本机手写识别。 |

四个 Android APK 的包名和正式签名相同，选择一个安装即可。已安装同签名旧版的用户可以直接覆盖安装。公开包已包含最新的候选词调整。学堂版的文献原件链接由系统浏览器打开。

安装包来自通过签名与覆盖安装测试的构建，源码提交为 `4ea8239`。校验值见 `SHA256SUMS`。
