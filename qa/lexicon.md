## 汉语借词的本字

22 个经过借源和本字核对的词义采用原汉字。键入拼写、手写本字或保留的旧写法共 97/97 次正确显示本字并省去字上短释义。土家语拼写与手写转拼写 44/44 次仍显示释义。当前词模没有生成指向这组借词的词级联想。例如输入 `sanggo` 或手写“伤哥”可选到“山歌”；切换到土家语拼写，候选 `sānggō` 上方显示“山歌”。

## 复现

在仓库根目录运行下列命令。依赖 Python 3、Node.js、C++17 编译器，以及包含学堂逐词标注和转换脚本的本地快照。

```sh
python3 qa/lexicon.py --site /workspace/bizic-dictionary/site --out /tmp/lexicon.md
```

本评测直接调用实际 C ABI。词条覆盖反映当前表内的一致性与候选次序。自由口语和真实使用时发生的输入错误需要另行取样。安卓系统输入框的手写选义与候选提交见[设备实测](device.md)。
